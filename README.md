# Pila
Este programa en lenguaje C que yo lo llamo pila basica, implementa una estructura de datos tipo pila (stack) utilizando un arreglo estático. Permite realizar operaciones básicas como:
	•	Agregar (push) elementos a la pila.
	•	Eliminar (pop) el elemento del tope.
	•	Consultar el tope sin eliminarlo.
	•	Verificar si la pila está vacía.

Incluye un menú interactivo para que el usuario pueda usar estas funciones desde consola. Es una implementación sencilla y funcional para practicar el uso de pilas en C.
